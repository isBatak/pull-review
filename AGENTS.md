# Agent instructions

## Replies to the user

Keep replies to the user at a Flesch-Kincaid Grade Level of 6 or lower.

- Use short sentences, about 15 words or less.
- Use short, common words. Write "use", not "utilize", and "help", not "facilitate".
- Code, file names and technical terms that have no simpler form are fine.

This applies to chat replies. It does not apply to code, commit messages or docs written for other readers, unless the user asks.
